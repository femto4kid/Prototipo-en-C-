# Sistema de matrícula escolar

Prototipo desarrollado en C# con Visual Studio Code,
basado en un algoritmo elaborado en PSeInt.

## Funciones
- Registro de alumnos de inicial, primaria y secundaria.
- Búsqueda por DNI.
- Validación de DNI, nombre y teléfono.
- Ordenamiento alfabético mediante el método burbuja.
- Reporte de alumnos.
- Guardado y recuperación de expedientes en un archivo de texto.

## Requisitos
- .NET SDK 10.

## Ejecución
Abrir una terminal en la carpeta del proyecto y ejecutar:

    dotnet run

## Datos
Utilizar datos ficticios para las pruebas.
El archivo expedientes.txt se genera al registrar alumnos
y está excluido del repositorio mediante .gitignore.
